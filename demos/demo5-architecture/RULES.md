# Demo 05 · Architecture｜生成式建筑规则

实时读取 C0–C5。每层保留功能，放置、移除、跨位置移动会立即重新计算局部形态。建筑不再限定为截角八面体；数字测试窗口仍用原硬件形状显示输入。

## 六类模块

| 编码 | 功能 | 建筑语言 | 邻接如何改变它 |
| --- | --- | --- | --- |
| C0 | Living 居住 | 灰白与石墨色错动立方体、水平窗缝 | 同类邻居提高实体密度；公共空间邻居切开中央廊道；花园增加种植槽 |
| C1 | Commons 公共 | 上下楼板、悬空空腔、斜撑 | 让直接相邻单元形成开敞画廊；邻接采光时出现明亮细节 |
| C2 | Garden 生境 | 穿孔曲面、多层薄膜、少量植物 | 接触采光变成半透明温室；光可沿同列连续花园链传递 |
| C3 | Passage 交通 | 开放框架、楼梯、细连接桥 | 与相邻功能模块之间生成实体步桥与细杆连接 |
| C4 | Atelier 工作室 | 递归细分立方骨架、双尺度网架 | 接触公共空间出现展廊；接触交通形成 Structural weave |
| C5 | Lantern 采光 | 折叠半透明表皮、竖向发光细肋 | 相邻模块降低实体密度、增加透光细节；花园变温室 |

界面保持深色，实体以灰白、炭黑、银灰为主，植物与透明表皮只保留轻微色偏。功能通过结构和空间辨认，而非依赖六种鲜艳颜色。

## 生成方式

| 项目 | 规则 |
| --- | --- |
| 单元内部 | 大多数模块拆为 3×3×3 子体素；工作室采用 4×4×4，并对选中的格子继续细分网架 |
| 可复现 | 子体素由模块 ID 和子格坐标的固定种子决定，同样输入不会因刷新数据而跳变 |
| 实体密度 | 基础 0.57，每个同类直接邻居 +0.055，公共邻居 −0.18，采光影响 −0.08；限制在 0.20–0.85 |
| 开洞优先 | 公共空间会切开中央一排子格；覆盖实体规则以保留通道 |
| 形态类型 | 生境、交通与工作室保留各自薄膜 / 楼梯 / 骨架类型，不会因为密度变大变成普通实心住宅 |
| 连接 | 沿真实邻接生成细结构；包含交通模块的连接增加步桥，错位半层同样适用 |
| 几何作用范围 | 输入位置仍是模块锚点；一块可呈现多个立方体、薄膜或网架，但不产生新的硬件模块 |

## 多模块涌现

| 名称 | 条件 | 结果 |
| --- | --- | --- |
| Aggregated mass | 住宅直接连接至少两个住宅 | 更密集的实体组合 |
| Open studios | 工作室直接连接公共空间 | 中央开放展廊、展陈光带 |
| Structural weave | 工作室直接连接交通 | 细密网架与连接桥组合 |
| Garden living | 住宅直接连接花园 | 居住体量出现种植槽 |
| Vertical greenhouse | 同列连续花园链获得采光影响 | 薄膜转为半透明，并保留每层植被 |
| Vertical neighborhood | 同一连通组至少两个住宅、两个交通 | 多层居住与楼梯 / 步桥组合 |
| Neighborhood commons | 同一连通组含住宅、公共、花园 | 提示邻里功能组合成立；细节仍按直接邻接计算 |
| Makers’ street | 同一连通组含工作室、公共、交通 | 形成工作与展廊交通网络 |
| Sheltered courtyard | 一个空地位置四个正交方向均被地面模块包围 | 空位出现生境嵌片；填满后取消 |

这是可交互的生成式空间表达，没有结构力学、建筑规范或人员寻路计算。

## 位置与测试

- 8 块 2×4 板，A0–A7；64 个基础位置和 64 个错位半层位置。
- Test view → Test board → 选择板号 → Position → Module → Add block。
- 同层轴向差 1、同列上下差 1，或三个轴均差 0.5 时建立邻接；只在平面斜着靠近不连接。
- 首块自动取景，此后新增模块不自动移动已有物体或镜头；Reset view 主动查看全部组合。
- Load sample 提供 Porous monolith、Distributed atelier、Living lattice 三种样例。
- 改变板排列保留板内内容，但按新的布局重新计算位置；模拟不写入实体设备。

## 一键随机测试

打开 **Test view** 直接进入独立模拟，不连接或写入硬件。选择一种 **Unit** 后，每点一次 **Add unit** 增加一个模块，实时更新场景。关闭面板仍保留模拟场景；顶部 **Return to hardware** 切回真实输入。

| 操作 / 规则 | 行为 |
| --- | --- |
| Unit 按钮 | 选择六类模块之一，选择本身不生成 |
| Add unit | 82% 优先落在板阵中央区域，18% 尝试外围；不会移动已有模块 |
| 聚集与堆叠 | 中央区域偏向已有模块附近；28% 尝试在已有位置堆叠，其余优先空位。无合适位置时回退至可用位置 |
| 容量 | 保留 8 个 2×4 底板及错层位置，每列最多 7 层；满板时停用添加 |
| Undo | 恢复上一次添加、手动编辑、清空、样例或布局修改前的状态，最多保留 100 步 |
| Precise placement & board layout | 展开后仍可指定板子、位置与堆叠，用于精确联调 |
| Block monitor | 默认收起，按需查看数字积木 |

随机位置由本 demo 的 `worldblocks/src/randomPlacement.mjs` 决定；生成规则和硬件协议保持不变。选择基于当前板阵布局，切换模块类型不会清空已有模块。
