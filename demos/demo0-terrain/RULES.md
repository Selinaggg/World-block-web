# Demo 00 · Terrain｜规则说明

> 本文描述当前已有脚本的真实行为。本次仅新增说明，不修改 Terrain 的代码或画面。

## 1. 规则从哪里来

| 部分 | 文件 | 负责什么 |
| --- | --- | --- |
| 硬件编码转玩法含义 | `worldblocks/src/terrainInput.mjs` | 根据首页保存的 C0–C5 含义，将输入转为地形类型 |
| 类型定义与可见层 | `worldblocks/src/terrainRules.js` | 定义土地、水、火山、空层、植被、房屋 |
| 空间位置 | `worldblocks/src/layout.js` | 底板排列、位置与半层错位 |
| 地形与装饰 | `worldblocks/src/TerrainScene.jsx` | 连接岛体、地层颜色、水池、熔岩、植物、建筑 |
| 界面与测试窗口 | `worldblocks/src/TerrainApp.jsx` | 实时输入、Test view、本地测试板 |

**输入变化 → 完整状态替换 → 重新计算当前地形。** 不需要 Generate，不调用图片或视频生成服务。

## 2. 六种模块

以下为默认映射。Terrain 的真实硬件模式遵循首页 Hardware settings 保存的映射；如果改过映射，应以保存的配置为准。本地 Test board 使用下表的默认映射。

| 默认编码 | 玩法类型 | 放在最上面的可见层时 | 放在下面时 |
| --- | --- | --- | --- |
| C0 | Earth / Land 土地 | 黄褐色陆地 | 黄褐色地层，参与岛体形状与高度 |
| C1 | Fire / Volcano 火山 | 黑色火山地貌与橙红熔岩池 | 黑色地层；符合条件的单层可形成中间熔岩台地 |
| C2 | Animal / Grass 植被 | 绿色地表、低多边形植物与花 | 绿色地层；不会在每个被覆盖的地层单独长一套植物 |
| C3 | Human / House 建筑 | 顶部出现小房屋 | 保留对应地层；被覆盖后不继续在该层重复生成房屋 |
| C4 | Water 水 | 蓝色水池与岸线 | 符合条件的单层可形成中间水面台地 |
| C5 | Support → Spacer 空层 | 自身不生成地形，也不覆盖下面的可见类型 | 底部空层抬高上方地形，形成浮空效果 |

**Terrain 的原规则是“地层 + 最高非空层表面”。** 它与 Ocean / Architecture 的“每一个模块都是独立生态角色或建筑单元”不同。

## 3. 堆叠与空层

| 自底向上的例子 | 结果 |
| --- | --- |
| 土地 → 植被 | 下方土地，上方绿色表面与植物 |
| 土地 → 房屋 | 土地上方出现房屋 |
| 土地 → 房屋 → 植被 | 保留地层，最高表面为植物；房屋不会继续作为被埋住的独立房间存在 |
| 空层 → 房屋 | 房屋所在岛体被抬起，下面留空 |
| 土地 → 空层 | 仍显示土地；顶端空层本身不可见 |
| 只有空层 | 不出现岛体 |
| 土地 → 空层 → 房屋 | 中间空层被过滤；当前原实现不会额外增加一整层可见地层高度 |

技术上，原脚本先保留各可见块的原始索引，再以**最底部可见层的索引**计算抬升，以**可见层数量**计算实体高度。因此它不是严格逐层保留内部空洞的体素系统。本文记录这一现状，不改变原逻辑。

## 4. 相邻与涌现

| 条件 | 实际结果 |
| --- | --- |
| 水平距离小于网格间距的 1.24 倍，且满足岛体连接条件 | 合成连续地形，而非简单并排的小山 |
| 两块都是落地地形 | 可连接成同一个岛体 |
| 一块落地、一块浮空 | 不合并为同一岛体 |
| 两块都是浮空地形，底部高度差小于约 0.36 场景单位 | 可合并为浮空岛体 |
| 相邻水面，且逻辑顶层高度相同 | 合成连续水池或水域 |
| 相邻熔岩面，且逻辑顶层高度相同 | 合成连续熔岩区域 |
| 同类水/熔岩，处于特定的 1 与 1.5 逻辑高度组合 | 生成半层连接通道；不是任意高度都自动连通 |
| 顶部连续两个或更多水/火模块 | 顶部液体区域收窄，形成更明显的坑口与岸壁 |
| 非顶层的单个水/火层 | 可生成中间液体台地；连续两个以上的中间液体层不走这条规则 |
| 较高的房屋地形 | 更倾向生成一个建筑；较低且有空间的顶部可出现小建筑群 |

植物与房屋的细节由位置 ID 的稳定种子决定。同一布局不会每帧重新随机；邻居变化使岛体重新组合时，局部轮廓也可能改变。

## 5. 推荐测试顺序

| 步骤 | 操作 | 应观察到 |
| --- | --- | --- |
| 1 | 空板 | 空场景，无自动样例 |
| 2 | 同一位置分别测试六种编码 | 对应地形效果；空层单独不可见 |
| 3 | 土地上叠植被 | 高度增加，表面变绿 |
| 4 | 移除植被 | 恢复较低的土地 |
| 5 | 将土地移到另一位置 | 原位置消失，新位置出现 |
| 6 | 并排放两个水模块 | 满足同高条件时形成连续水面 |
| 7 | 空层上叠房屋 | 浮空地形 |
| 8 | 断开并重新接入硬件 | 断开时标记连接状态，重连后以完整新状态替换 |

Test view 默认隐藏。Test board 是独立本地模拟；Clear test board 不会重置实体硬件。软件测试不能替代真实硬件联调。

## 星球地表

场景底部增加固定存在的暖棕色星球表面，沿用土块的 `#c79756` 土色，并在接地处向 `#9a7244` 土层侧色过渡。地表有轻微起伏，外围逐渐向下弯曲；覆盖模块的中央区域保持原有接地高度，避免底部悬空。

地表是视觉环境，不代表新增硬件块，不计入数量，也不改变水坑、火山、堆叠、浮空或邻接规则。其覆盖范围随当前地形调整。实现位于 `worldblocks/src/planetSurface.js`，由 `TerrainScene.jsx` 挂载并更新。

## 八板模拟测试

| 项目 | 行为 |
| --- | --- |
| 底板 | 8 块 2×4 板，编号 A0–A7 |
| 位置 | 64 个 L0 基础位置＋64 个 L0.5 半层位置，共 128 列 |
| 排列 | 默认 4 行 × 2 列板，可切换 8×1、2×4、1×8 |
| 操作 | Test view → Test board → 板号 → Position → Block → Add block |
| 改变排列 | 保留各板的积木内容，按新的板排列重新计算位置 |

此面板只修改模拟数据，不改变首页保存的实体硬件配置。

## 星球氛围渲染

背景由纯黑改为青灰暮色天空，包含缓慢变化的高空薄云、暖色侧光、冷色轮廓光、远景薄雾和少量漂浮微粒。星球和土块共享这一套光照与色调映射，原有生成、融合、地层、水坑和浮空规则不变。减少动态效果的系统设置会冻结环境动画。

氛围实现位于 `worldblocks/src/atmosphere.js`；界面仍保留深色工具栏和默认隐藏的数字测试窗口。


## 一键随机测试

打开 **Test view** 直接进入独立模拟，不连接或写入硬件。选择一种 **Unit** 后，每点一次 **Add unit** 增加一个模块，实时更新场景。关闭面板仍保留模拟场景；顶部 **Return to hardware** 切回真实输入。

| 操作 / 规则 | 行为 |
| --- | --- |
| Unit 按钮 | 选择六类模块之一，选择本身不生成 |
| Add unit | 82% 优先落在板阵中央区域，18% 尝试外围；不会移动已有模块 |
| 聚集与堆叠 | 中央区域偏向已有模块附近；28% 尝试在已有位置堆叠，其余优先空位。无合适位置时回退至可用位置 |
| 容量 | 保留 8 个 2×4 底板及错层位置，每列最多 7 层；满板时停用添加 |
| Undo | 恢复上一次添加、手动编辑、清空、样例或布局修改前的状态，最多保留 100 步 |
| Precise placement & board layout | 展开后仍可指定板子、位置与堆叠，用于精确联调 |
| Block monitor | 默认收起，按需查看数字积木 |

随机位置由本 demo 的 `worldblocks/src/randomPlacement.mjs` 决定；生成规则和硬件协议保持不变。选择基于当前板阵布局，切换模块类型不会清空已有模块。
